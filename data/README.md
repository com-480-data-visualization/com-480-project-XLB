# Data Pipeline

CineScope uses [The Movies Dataset](https://www.kaggle.com/datasets/rounakbanik/the-movies-dataset), originally sourced from TMDb and linked with MovieLens ratings.

## Directory Structure

```text
data/
|-- raw/                        # Downloaded Kaggle CSV files; not committed
|   |-- movies_metadata.csv
|   |-- credits.csv
|   |-- keywords.csv
|   |-- ratings.csv
|   `-- links.csv
|-- processed/                  # Generated by eda/preprocessing.ipynb; not committed
|   `-- movies.csv
`-- web/                        # Generated compact exports consumed by the site
    |-- movies.json
    |-- franchises.json
    |-- directors.json
    `-- summary.json
```

## Source And Processed Data

`eda/preprocessing.ipynb` joins and cleans the Kaggle source files. Its `movies.csv` output has 45,697 rows and includes:

| Field group | Examples |
| --- | --- |
| Identification and time | `id`, `title`, `year`, `decade`, `release_date` |
| Financials | `budget`, `revenue` |
| Film attributes | `runtime`, `genres_list`, `director`, `top_cast` |
| Audience measures | `vote_average`, `vote_count`, `movielens_avg_rating`, `movielens_vote_count` |

Zero values in raw `budget` and `revenue` fields represent unavailable financial records and are excluded from financial analysis.

## Browser Exports

Run the web export after generating `data/processed/movies.csv`:

```bash
python3 scripts/export_web_data.py
```

| File | Purpose |
| --- | --- |
| `movies.json` | Eligible individual film records for charts and filters |
| `franchises.json` | TMDb collections, their measurable installments, and sequel comparisons |
| `directors.json` | Director-level portfolio summaries |
| `summary.json` | Rules, counts, headline observations, and displayed narrative values |

## Analysis Rules

| Rule | Implementation |
| --- | --- |
| Financial subset | Positive reported revenue and budget of at least `$10,000` |
| Coverage | Films released no later than 2017 |
| Duplicate handling | One record per TMDb ID, retaining the greater recorded revenue where duplicates occur |
| ROI | `revenue / budget`, interpreted as gross multiplier rather than net profit |
| Rating evidence | MovieLens comparisons require at least 50 votes |
| Dynasties | All financially eligible later installments are compared with the earliest eligible original in each TMDb collection |

Before the documented web-export floor and ID de-duplication, 5,417 processed rows have positive budget and revenue. The browser exports contain **5,317 financially eligible films**, **309 collections**, and **573 sequel-to-original comparisons**.

The budget floor removes unstable ratios driven by implausibly tiny recorded production costs while retaining a genuine low-budget outlier such as *Paranormal Activity*, whose recorded budget is `$15,000`. Financial coverage remains biased toward theatrically reported films, and box-office revenue does not include marketing costs or ancillary income.
